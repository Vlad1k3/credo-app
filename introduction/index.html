    Introduction

    Introduction¶

    Why This Tool Exists¶

    The official Credo Bank interface provides basic transaction history but lacks meaningful analytical tools. Questions like "What's my biggest expense category?", "Am I saving more this quarter than last?", or "How stable is my income month-to-month?" require exporting data to spreadsheets and building charts manually.

    Most third-party financial tools require linking your bank account or uploading statements to external servers. Credo Statement Analyzer was built to answer these questions without sacrificing privacy.

    What It Does¶

    The tool transforms raw bank exports into an interactive dashboard:

    Feature Description
    Income & Expense Summary Total income, total expense, net result, daily/monthly averages
    Category Breakdown Automatic categorization via 90+ merchant regex patterns into groups like Grocery, Taxi, Utilities
    Balance Timeline Line chart showing combined account balance over time
    Savings Rate Monthly savings rate chart: what percentage of income was saved each month
    Period Comparison Compare current month/week/year against the previous one with percentage changes
    Financial Insights Stability score, vampire expenses, day-of-week patterns, category trends, living standard progress
    Transaction Table Searchable, filterable, sortable list with detail modals
    Multi-Currency Automatic conversion between GEL, USD, EUR using historical NBG rates
    Custom Date Range Analyze any arbitrary date range (e.g., a vacation, a project, a quarter)

    Privacy First¶

    Your financial data never leaves your device.

    • All file parsing happens in the browser via JavaScript
    • Transaction data is stored in localStorage (never sent to any server)
    • The only external request is fetching exchange rates from the NBG API — and only when you have multi-currency accounts
    • The app works fully offline after first load
    • Click "New File" to wipe all data from the browser instantly

    Technology¶

    Layer Technology
    Framework React 18 (Vite)
    Charts Chart.js + react-chartjs-2
    PDF Parsing pdfjs-dist
    Excel Parsing SheetJS (xlsx)
    Exchange Rates National Bank of Georgia REST API
    Styling Vanilla CSS with custom properties, dark/light theme
    Localization English + Russian (built-in i18n context)

    Введение¶

    Зачем создан этот инструмент¶

    Официальный интерфейс Credo Bank предоставляет базовую историю транзакций, но не имеет полноценных аналитических инструментов. На вопросы вроде «Какая у меня самая большая категория расходов?», «Сберегаю ли я в этом квартале больше, чем в прошлом?» или «Насколько стабилен мой доход из месяца в месяц?» приходится отвечать, экспортируя данные в таблицы и строя графики вручную.

    Большинство сторонних финансовых инструментов требуют привязки банковского счёта или загрузки выписок на внешние серверы. Credo Statement Analyzer был создан, чтобы отвечать на эти вопросы без ущерба для конфиденциальности.

    Что он делает¶

    Инструмент преобразует необработанные банковские экспорты в интерактивную панель:

    Функция Описание
    Сводка доходов и расходов Общий доход, общий расход, чистый результат, среднедневные/среднемесячные значения
    Разбивка по категориям Автоматическая категоризация по 90+ regex-шаблонам мерчантов в группы: Продукты, Такси, Коммунальные услуги
    График баланса Линейный график совокупного баланса счетов во времени
    Норма сбережений Ежемесячный график нормы сбережений: какой процент дохода был сохранён в каждом месяце
    Сравнение периодов Сравнение текущего месяца/недели/года с предыдущим с процентными изменениями
    Финансовые выводы Оценка стабильности, расходы-«вампиры», паттерны по дням недели, тренды категорий, прогресс уровня жизни
    Таблица транзакций Список с поиском, фильтрацией, сортировкой и модальными окнами с деталями
    Мультивалютность Автоматическая конвертация между GEL, USD, EUR по историческим курсам НБГ
    Произвольный период Анализ любого произвольного диапазона дат (например, отпуск, проект, квартал)

    Конфиденциальность прежде всего¶

    Ваши финансовые данные никогда не покидают ваше устройство.

    • Вся обработка файлов происходит в браузере с помощью JavaScript
    • Данные транзакций хранятся в localStorage (никогда не отправляются на сервер)
    • Единственный внешний запрос — получение обменных курсов из API НБГ — и только при наличии мультивалютных счетов
    • Приложение полностью работает офлайн после первой загрузки
    • Нажмите «New File», чтобы мгновенно удалить все данные из браузера
