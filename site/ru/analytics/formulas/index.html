    Формулы и расчёты¶

    Основные финансовые метрики¶

    Общий доход¶

    \[ \text{Total Income} = \sum_{i=1}^{N} \text{credit}_i \]

    Где credit — сумма поступления по каждой транзакции. Транзакции с credit = 0 являются расходами и исключаются из этой суммы.

    Пример: Если вы получили три платежа на 1000, 2500 и 500 GEL:

    \[ \text{Total Income} = 1000 + 2500 + 500 = 4000 \text{ GEL} \]

    Общий расход¶

    \[ \text{Total Expense} = \sum_{i=1}^{N} \text{debit}_i \]

    Где debit — сумма списания. Транзакции с debit = 0 являются доходами и исключаются.

    Чистый результат¶

    \[ \text{Net} = \text{Total Income} - \text{Total Expense} \]
    • Положительный (зелёный): вы заработали больше, чем потратили
    • Отрицательный (красный): вы потратили больше, чем заработали

    Средний дневной расход¶

    \[ \text{Avg Daily Expense} = \frac{\text{Total Expense}}{D} \]

    Где \(D\) — количество уникальных дней, в которые была хотя бы одна транзакция (не календарных дней).

    Пример: 3000 GEL потрачено за 20 уникальных дней = 150 GEL/день

    Средний месячный расход¶

    \[ \text{Avg Monthly Expense} = \frac{\text{Total Expense}}{M} \]

    Где \(M\) — количество уникальных месяцев, в которые была хотя бы одна транзакция.

    Баланс¶

    Начальный баланс¶

    Вычисляется из первой транзакции в наборе данных:

    \[ \text{Starting Balance} = \text{balance}_1 - (\text{credit}_1 - \text{debit}_1) \]

    Это восстанавливает баланс, существовавший до первой транзакции.

    Текущий баланс¶

    Поле balance последней транзакции в отсортированном наборе данных.

    Совокупный конечный баланс (мультисчёт)¶

    При загрузке нескольких файлов счетов каждый предоставляет Closing Balance в информации о счёте. Совокупный баланс рассчитывается так:

    \[ \text{Combined Balance} = \sum_{a \in \text{accounts}} \text{convert}(\text{Closing Balance}_a, \text{currency}_a, \text{display currency}) \]

    Если совокупный конечный баланс отличается от расчётного нетто более чем на 0.05, добавляется корректирующая поправка:

    \[ \text{Adjustment} = \text{Combined Closing Balance} - \text{Net} \]

    Это устраняет расхождения, возникающие из-за транзакций за пределами экспортируемого диапазона дат.

    Норма сбережений¶

    Рассчитывается за каждый календарный месяц:

    \[ \text{Savings}_m = \text{Income}_m - \text{Expense}_m \]
    \[ \text{Savings Rate}_m = \begin{cases} \frac{\text{Income}_m - \text{Expense}_m}{\text{Income}_m} \times 100 & \text{if } \text{Income}_m > 0 \\ 0 & \text{otherwise} \end{cases} \]

    Пример:

    Месяц Доход Расход Сбережения Норма
    Янв 5000 3500 1500 30.0%
    Фев 5000 5200 -200 -4.0%
    Мар 0 800 -800 0%

    Сравнение периодов¶

    Сравнивает текущий период с предыдущим, используя дневные средние для нормализации при разной длине периодов.

    Статистика периода¶

    Для набора транзакций за период:

    \[ \text{Avg Daily Income} = \frac{\sum \text{credit}_i}{D} \]
    \[ \text{Avg Daily Expense} = \frac{\sum \text{debit}_i}{D} \]
    \[ \text{Savings Rate} = \frac{\text{Income} - \text{Expense}}{\text{Income}} \times 100 \]

    Процентное изменение¶

    \[ \Delta\% = \frac{\text{Current} - \text{Previous}}{|\text{Previous}|} \times 100 \]

    Граничный случай: если \(\text{Previous} = 0\) и \(\text{Current} > 0\), изменение составляет \(+100\%\).

    Для нормы сбережений изменение выражается в процентных пунктах:

    \[ \Delta_{pp} = \text{Savings Rate}_{\text{current}} - \text{Savings Rate}_{\text{previous}} \]

    Изменения по категориям¶

    Изменение расходов по категориям между текущим и предыдущим периодом:

    \[ \Delta_{\text{cat}} = \sum_{\text{current}} \text{debit}_{\text{cat}} - \sum_{\text{previous}} \text{debit}_{\text{cat}} \]
    \[ \Delta\%_{\text{cat}} = \frac{\Delta_{\text{cat}}}{\sum_{\text{previous}} \text{debit}_{\text{cat}}} \times 100 \]

    Отображаются только 5 категорий с наибольшим абсолютным изменением.

    Оценка финансовой стабильности¶

    Составная оценка от 0 до 100, вычисленная на основе трёх подоценок.

    Подоценки¶

    1. Стабильность дохода — на основе коэффициента вариации ежемесячного дохода:

    \[ \text{CV}_{\text{income}} = \frac{\sigma(\text{monthly incomes})}{\mu(\text{monthly incomes})} \]
    \[ \text{Income Score} = \text{clamp}(100 - \text{CV}_{\text{income}} \times 100, \; 0, \; 100) \]

    Идеально стабильный доход (одинаковая сумма каждый месяц) получает оценку 100. Высоко волатильный доход — оценку близкую к 0.

    2. Стабильность расходов — та же формула, применённая к ежемесячным расходам:

    \[ \text{Expense Score} = \text{clamp}(100 - \text{CV}_{\text{expense}} \times 100, \; 0, \; 100) \]

    3. Постоянство сбережений — процент месяцев, в которых доход превышал расходы:

    \[ \text{Savings Score} = \frac{|\{m : \text{Income}_m > \text{Expense}_m\}|}{|\text{Total Months}|} \times 100 \]

    Составная оценка¶

    \[ \text{Overall} = \text{clamp}\Big(0.35 \times \text{Income Score} + 0.30 \times \text{Expense Score} + 0.35 \times \text{Savings Score}, \; 0, \; 100\Big) \]

    Интерпретация:

    Оценка Уровень Значение
    70–100 Отлично Стабильный доход, контролируемые расходы, регулярные сбережения
    40–69 Средне Некоторая волатильность, периодические перерасходы
    0–39 Плохо Высоко волатильный доход/расходы, сбережения редки

    Пример: 12 месяцев данных, коэффициент вариации дохода = 0.15, коэффициент вариации расходов = 0.25, 9 из 12 месяцев положительные:

    • Оценка дохода = clamp(100 - 15, 0, 100) = 85
    • Оценка расходов = clamp(100 - 25, 0, 100) = 75
    • Оценка сбережений = (9/12) x 100 = 75
    • Итого = 0.35 x 85 + 0.30 x 75 + 0.35 x 75 = 29.75 + 22.5 + 26.25 = 78.5

    Расходы-вампиры¶

    Небольшие повторяющиеся списания, которые по отдельности кажутся незначительными, но накапливаются со временем.

    Критерии обнаружения¶

    Торговая точка квалифицируется как «вампир», если:

    1. Сумма отдельной транзакции < 15 GEL (настраиваемый порог)
    2. Торговая точка встречается в 3 или более уникальных датах

    Метрики¶

    Метрика Формула
    Количество Число подходящих транзакций
    Итого \(\sum \text{debit}_i\) для данной торговой точки
    Среднее \(\frac{\text{Total}}{\text{Count}}\)
    Частота Количество уникальных дат

    Результаты отсортированы по убыванию итоговой суммы, максимум 6 торговых точек.

    Пример: Вы покупаете кофе в «STARBUCKS» за 8 GEL, 12 раз за 10 разных дней:

    • Количество: 12, Итого: 96 GEL, Среднее: 8 GEL, Частота: 10

    Паттерны по дням недели¶

    Средний дневной расход по дням недели (с понедельника по воскресенье).

    \[ \text{Avg}_{\text{weekday}} = \frac{\sum_{\text{txs on weekday}} \text{debit}_i}{|\text{unique dates on weekday}|} \]

    Дни используют индексацию с понедельника: Пн=0, Вт=1, ..., Вс=6.

    Пиковый день (с наибольшим средним) выделяется на графике.

    Тренды по категориям¶

    Сравнивает средние ежемесячные расходы по категориям между первой и второй половиной ваших данных.

    Алгоритм¶

    1. Собрать все уникальные месяцы, отсортировать хронологически
    2. Разделить по средней точке: firstHalf = months[0..mid-1], secondHalf = months[mid..end]
    3. Для каждой категории расходов:
    \[ \text{Change}\% = \frac{\text{Avg}_{\text{second}} - \text{Avg}_{\text{first}}}{\text{Avg}_{\text{first}}} \times 100 \]
    1. Категории, где оба средних значения ниже 5, исключаются (шум)
    2. Отображаются 6 категорий с наибольшим абсолютным процентным изменением

    Пример: Продукты в среднем 800/месяц в первой половине, 950/месяц во второй:

    \[ \text{Change} = \frac{950 - 800}{800} \times 100 = +18.75\% \]

    Прогресс уровня жизни¶

    Сравнивает средний доход, расход и сбережения между первой и второй половиной ваших данных.

    \[ \text{Income Change}\% = \frac{\text{Avg Income}_{\text{2nd}} - \text{Avg Income}_{\text{1st}}}{\text{Avg Income}_{\text{1st}}} \times 100 \]
    \[ \text{Savings Change} = (\text{Avg Income}_{\text{2nd}} - \text{Avg Expense}_{\text{2nd}}) - (\text{Avg Income}_{\text{1st}} - \text{Avg Expense}_{\text{1st}}) \]

    Пример: Первая половина: средний доход 5000, средний расход 4000. Вторая половина: средний доход 6000, средний расход 4500.

    • Изменение дохода: +20%, Изменение расходов: +12.5%, Изменение сбережений: +500 GEL

    Конвертация валют¶

    Все конвертации используют GEL как промежуточную валюту через курсы НБГ.

    \[ \text{GEL per 1 unit} = \frac{\text{rate}}{\text{quantity}} \]
    \[ \text{amount}_{\text{target}} = \frac{\text{amount}_{\text{source}} \times (\text{rate}_{\text{source}} / \text{quantity}_{\text{source}})}{(\text{rate}_{\text{target}} / \text{quantity}_{\text{target}})} \]

    Пример: Конвертация 100 USD в EUR. Курс USD=2.6856, курс EUR=2.9123:

    \[ \frac{100 \times 2.6856}{2.9123} = 92.21 \text{ EUR} \]

    См. Обменные курсы для полного описания системы.

    Округление¶

    Все финансовые расчёты используют округление до 2 знаков после запятой:

    function round(n) {
    return Math.round(n * 100) / 100;
}
