# Обменные курсы

Credo Statement Analyzer поддерживает мультивалютные счета, конвертируя все значения в единую валюту отображения с использованием исторических обменных курсов Национального банка Грузии (NBG).

## Когда требуются курсы

Обменные курсы запрашиваются только когда:

1. Обнаружены **несколько валют счетов** (например, загружены файлы GEL + USD)
2. **И** пользователь выбрал валюту отображения, отличную от основной валюты, или необходимо конвертировать конечные балансы счетов (cross-currency conversion)

Если у вас только одновалютные счета, запросы курсов не выполняются.

## Источник данных

**API**: Национальный банк Грузии
**Эндпоинт**: `https://nbg.gov.ge/gw/api/ct/monetarypolicy/currencies/en/json/?date=YYYY-MM-DD`

Каждый ответ API содержит массив валют:

| Поле | Описание | Пример |
|------|----------|--------|
| `code` | Код валюты ISO 4217 | `USD` |
| `rate` | GEL за `quantity` единиц | `2.6856` |
| `quantity` | Количество единиц, к которым применяется курс | `1` |

### Значение курса

$$
1 \text{ единица валюты} = \frac{\text{rate}}{\text{quantity}} \text{ GEL}
$$

Для большинства валют `quantity = 1`. Для некоторых (например, Японская иена), `quantity = 100`.

## Стратегия получения данных

### Предварительная выборка

Когда обнаружены мультивалютные счета, приложение:

1. Извлекает все **уникальные даты транзакций** из набора данных
2. Отфильтровывает даты, уже имеющиеся в кэше
3. Запрашивает недостающие даты **параллельными пакетами по 5**, чтобы не перегружать API

### Кэширование

Курсы кэшируются на двух уровнях:

| Кэш | Хранилище | Время жизни |
|-----|-----------|-------------|
| В памяти | Объект JavaScript | Текущая сессия |
| localStorage | Ключ: `credo_nbg_rates` | Постоянно между сессиями |

Структура кэша:

```json
{
  "2025/08/14": {
    "USD": { "rate": 2.6856, "quantity": 1 },
    "EUR": { "rate": 2.9123, "quantity": 1 }
  },
  "2025/08/15": { ... }
}
```

### Резервный вариант для отсутствующих дат

Если конкретной даты нет в кэше (ошибка API, выходной/праздник без опубликованного курса):

1. **Бинарный поиск** находит точку вставки в отсортированном списке дат
2. Алгоритм ищет вовне от этой точки (чередуя влево/вправо) ближайшую дату, у которой есть курс для требуемой валюты
3. Если курс вообще не найден, коэффициент конвертации по умолчанию равен **1** (без конвертации)

## Алгоритм конвертации

Все конвертации проходят через GEL как посредника:

```
Исходная Валюта → GEL → Целевая Валюта
```

### Пошагово

1. **Исходная в GEL**:

$$
\text{amount}_{\text{GEL}} = \text{amount}_{\text{source}} \times \frac{\text{rate}_{\text{source}}}{\text{quantity}_{\text{source}}}
$$

2. **GEL в Целевую** (пропустить, если целевая GEL):

$$
\text{amount}_{\text{target}} = \frac{\text{amount}_{\text{GEL}}}{\text{rate}_{\text{target}} / \text{quantity}_{\text{target}}}
$$

### Конвертация транзакции

При конвертации полной транзакции все денежные поля конвертируются индивидуально:

- `debit` — сумма списания
- `credit` — сумма поступления
- `balance` — баланс счёта на тот момент
- `amount` — абсолютная сумма транзакции

Каждое поле использует обменный курс на **конкретную дату этой транзакции**. Исходная валюта сохраняется в поле `originalCurrency`.

### Конвертация конечного баланса

При расчёте совокупного конечного баланса по нескольким счетам, конечный баланс каждого счёта конвертируется с использованием курса на **дату последней транзакции** в наборе данных.

## Обработка ошибок

| Сценарий | Поведение |
|----------|-----------|
| API возвращает статус не 200 | Эта дата получает пустую карту курсов; откат к ближайшей дате |
| API недоступен (офлайн) | Используются ранее кэшированные курсы; новые даты используют откат |
| Превышена квота `localStorage` | Кэш работает только в памяти для этой сессии |
| Курс валюты не найден | Коэффициент конвертации = 1 (сумма без изменений) |

## Поддерживаемые валюты

API NBG предоставляет курсы для 40+ валют. Приложение специально обрабатывает эти с выделенными символами:

| Валюта | Символ |
|--------|--------|
| GEL | ₾ |
| USD | $ |
| EUR | € |
| RUB | ₽ |
| Другие | Код ISO (например, "GBP") |
