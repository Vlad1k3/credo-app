# Временные периоды

Credo Analytics позволяет разрезать данные на пять временных перспектив для детальных сравнений.

### Доступные периоды

#### Просмотр по годам

Агрегирует транзакции за один календарный год.

- **Формат ключа периода**: `YYYY` (например, `2024`)
- **Фильтр**: все транзакции, где `date.startsWith("2024")`
- **График**: ежедневные столбцы доходов/расходов в пределах года
- **Навигация**: переключение между доступными годами с помощью `← →`

#### Просмотр по месяцам

Один календарный месяц.

- **Формат ключа периода**: `YYYY/MM` (например, `2024/07`)
- **Фильтр**: все транзакции, где `date.startsWith("2024/07")`
- **График**: ежедневные столбцы доходов/расходов в пределах месяца

#### Просмотр по неделям

С понедельника по воскресенье одной ISO-недели.

- **Формат ключа периода**: `YYYY/MM/DD` (понедельник этой недели)
- **Фильтр**: все транзакции с понедельника по воскресенье (7 дней)
- **Вычисление начала недели**: `dayOfWeek === 0 ? date - 6 : date - (dayOfWeek - 1)` (начало с понедельника)
- **Формат отображения**: `"4 Jul — 10 Jul, 2024"`

#### Просмотр по дням

Один день.

- **Формат ключа периода**: `YYYY/MM/DD`
- **Фильтр**: точное совпадение даты
- **Формат отображения**: `"14 January 2024"`

!!! note
    Просмотр по дням не включает сравнение периодов (нет осмысленного паттерна «предыдущий день»).

### Навигация по периодам

Когда активна любая вкладка периода (Год/Месяц/Неделя/День):

1. Приложение вычисляет все доступные ключи периодов из данных транзакций, сканируя каждую дату транзакции
2. Ключи сортируются хронологически
3. Панель навигации показывает `← Текущий период →` с текущим индексом
4. Центральная метка кликабельна — она открывает оверлей **Выбор периода**

#### Выбор периода

Селектор показывает прокручиваемую сетку/список всех доступных периодов:

- Для **Года/Месяца/Недели**: сетка кликабельных меток периодов
- Для **Произвольного диапазона**: два поля ввода дат (от/до)
- Нажмите на период, чтобы мгновенно перейти к нему
- Нажмите за пределами или на кнопку закрытия, чтобы закрыть

### Сравнение периодов

Для всех вкладок периодов, кроме «День», **карточка сравнения** показывает, как текущий период соотносится с предыдущим.

#### Что сравнивается

| Метрика | Формула | «Хорошее» направление |
|---------|---------|----------------------|
| Ср. дневной расход | $\frac{\text{Total Expense}}{\text{Unique Days}}$ | Чем меньше, тем лучше |
| Ср. дневной доход | $\frac{\text{Total Income}}{\text{Unique Days}}$ | Чем больше, тем лучше |
| Норма сбережений | $\frac{\text{Income} - \text{Expense}}{\text{Income}} \times 100$ | Чем больше, тем лучше |

#### Формула процентного изменения

$$
\Delta\% = \frac{\text{Current} - \text{Previous}}{|\text{Previous}|} \times 100
$$

Особый случай: если `Previous = 0` и `Current > 0`, изменение отображается как `+100%`.

Для нормы сбережений изменение показывается в **процентных пунктах** (п.п.), а не в процентах:

$$
\Delta_{pp} = \text{Current Rate} - \text{Previous Rate}
$$

#### Изменения по категориям

Отображаются 5 категорий с наибольшим абсолютным изменением расходов между периодами:

$$
\Delta_{\text{cat}} = \text{Current Spend}_{\text{cat}} - \text{Previous Spend}_{\text{cat}}
$$

Зелёный (↓) означает, что вы потратили меньше, красный (↑) — что потратили больше.

### Как определяется «предыдущий период»

| Текущая вкладка | Предыдущий период |
|-----------------|-------------------|
| Год `2024` | Все транзакции за `2023` |
| Месяц `2024/07` | Предыдущий доступный ключ месяца (например, `2024/06`) |
| Неделя `2024/07/01` | Предыдущий доступный ключ недели |
| День | Сравнение недоступно |
| Произвольный | Сравнение недоступно |

!!! info
    Предыдущий период использует **предыдущий доступный ключ** из отсортированного массива ключей, а не календарное смещение. Это означает, что если у вас есть данные за январь и март, но нет за февраль, предыдущим периодом для марта будет январь.
