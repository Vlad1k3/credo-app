# Шапка и элементы управления

Шапка является центром управления панелью мониторинга, предоставляя доступ к глобальным настройкам, управлению файлами и фильтрации данных.

### Элементы управления

| Элемент | Метка | Функция |
|---------|-------|---------|
| **Переключатель темы** | `🌙` / `☀️` | Переключает между светлой и тёмной темами. Сохраняется в `localStorage`. |
| **Язык** | `RU` / `EN` | Переключает язык интерфейса между английским и русским. |
| **Фильтр шума** | Иконка фильтра | Скрывает внутренние переводы (переводы между собственными счетами и обмен валют), показывая только реальные доходы/расходы. Активен по умолчанию. |
| **+ Добавить файлы** | `+ Add Files` | Загрузка дополнительных файлов выписок для объединения с существующими данными. Новые транзакции дедуплицируются автоматически. |
| **Новый файл** | `New File` | Очищает все данные транзакций в браузере и возвращает на экран загрузки. |

### Информация о счёте

Под заголовком отображается строка с информацией:

- **Владелец счёта** — имя из информации о счёте первого загруженного файла
- **Номера счетов** — если загружено несколько счетов, показывает их количество (например, "3 accounts")
- **Валюты** — сгруппированы по валюте с количеством (например, "2x GEL + USD")

Пример: `JOHN DOE · 3 accounts · 2x GEL + USD`

### Диапазон дат и количество транзакций

Вторая строка показывает:

- **Диапазон дат** — начальная и конечная даты всех загруженных транзакций (формат: `DD.MM.YYYY`)
- **Количество транзакций** — общее число анализируемых транзакций

Пример: `01.01.2024 — 31.12.2024 · 1,247 transactions`

### Переключатель валюты

Отображается только при обнаружении нескольких валют счетов. Нажмите на код валюты (например, **USD**, **GEL**), чтобы конвертировать все графики, сводки и итоги в эту валюту по историческим обменным курсам.

!!! info "Как работает конвертация"
    При переключении на неосновную валюту приложение загружает исторические курсы Национального банка Грузии для каждой уникальной даты транзакции, а затем конвертирует поля дебета, кредита, баланса и суммы каждой транзакции по отдельности. Подробности см. в разделе [Exchange Rates](../analytics/exchange-rates.md).

### Фильтр шума

Когда фильтр активен (по умолчанию), он скрывает две категории транзакций:

1. **Переводы между своими счетами** — перемещение средств между вашими счетами в Credo (определяется по шаблону `საკუთარ ანგარიშებს`)
2. **Обмен валют** — покупка/продажа валюты внутри ваших счетов (определяется по `კონვერტაცია`, `Exchange` и т.д.)

Это предотвращает завышение итогов доходов и расходов из-за внутренних перемещений средств. Например, перевод 1000 GEL с текущего счёта на сберегательный иначе отобразился бы и как расход в 1000 GEL, и как доход в 1000 GEL.

!!! tip
    Отключите фильтр, если хотите видеть полную историю транзакций, включая внутренние перемещения.
