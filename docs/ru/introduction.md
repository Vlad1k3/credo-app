# Введение

### Зачем этот инструмент существует

Официальный интерфейс Credo Bank предоставляет базовую историю транзакций, но лишён значимых аналитических инструментов. Вопросы вроде «Какая у меня самая большая категория расходов?», «Сберегаю ли я в этом квартале больше, чем в прошлом?» или «Насколько стабилен мой доход от месяца к месяцу?» требуют экспорта данных в таблицы и ручного построения графиков.

Большинство сторонних финансовых инструментов требуют привязки банковского счёта или загрузки выписок на внешние серверы. Credo Statement Analyzer был создан, чтобы ответить на эти вопросы **без ущерба для конфиденциальности**.

### Что он делает

Инструмент преобразует необработанные банковские выгрузки в интерактивную панель управления:

| Функция | Описание |
|---------|----------|
| **Сводка доходов и расходов** | Общий доход, общий расход, чистый результат, среднедневные/среднемесячные значения |
| **Разбивка по категориям** | Автоматическая категоризация через 90+ regex-шаблонов в группы: Продукты, Такси, Коммунальные услуги |
| **Хронология баланса** | Линейный график, показывающий совокупный баланс счетов во времени |
| **Норма сбережений** | График ежемесячной нормы сбережений: какой процент дохода был сохранён в каждом месяце |
| **Сравнение периодов** | Сравнение текущего месяца/недели/года с предыдущим с процентными изменениями |
| **Финансовые инсайты** | Оценка стабильности, расходы-«вампиры», паттерны по дням недели, тренды категорий, прогресс уровня жизни |
| **Таблица транзакций** | Список с поиском, фильтрацией, сортировкой и модальными окнами деталей |
| **Мультивалютность** | Автоматическая конвертация между GEL, USD, EUR с использованием исторических курсов НБГ |
| **Произвольный диапазон** | Анализ любого произвольного диапазона дат (например, отпуск, проект, квартал) |

### Конфиденциальность прежде всего

**Ваши финансовые данные никогда не покидают ваше устройство.**

- Весь парсинг файлов происходит в браузере через JavaScript
- Данные транзакций хранятся в `localStorage` (никогда не отправляются ни на какой сервер)
- Единственный внешний запрос — получение обменных курсов из [API НБГ](https://nbg.gov.ge) — и только при наличии мультивалютных счетов
- Приложение работает полностью офлайн после первой загрузки
- Нажмите «New File», чтобы мгновенно стереть все данные из браузера

### Технологии

| Уровень | Технология |
|---------|------------|
| Фреймворк | React 18 (Vite) |
| Графики | Chart.js + react-chartjs-2 |
| Парсинг PDF | pdfjs-dist |
| Парсинг Excel | SheetJS (xlsx) |
| Обменные курсы | REST API Национального банка Грузии |
| Стилизация | Vanilla CSS с пользовательскими свойствами, тёмная/светлая тема |
| Локализация | English + Russian (встроенный i18n контекст) |
