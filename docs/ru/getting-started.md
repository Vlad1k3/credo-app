# Загрузка и Настройка

### Поддерживаемые форматы файлов

Credo Statement Analyzer принимает три типа файлов, экспортируемых из Credo Bank:

#### XLSX (Excel) — Рекомендуется

Самый информативный формат. Парсер ищет два листа:

- **Детали счёта** (или "დეტალები") — владелец счёта, номер счёта, валюта, начальный/конечный баланс
- **Транзакции** (или "ტრანზაქცი") — таблица транзакций

Если эти названия листов не найдены, парсер использует последний лист рабочей книги.

#### PDF

Поддерживаются два формата PDF:

1. **Полная выписка по счёту** — многостраничная таблица со столбцами: Дата, Операция, Дебет, Кредит, Баланс, Описание, Бенефициар. Определяется по наличию "Account Statement" или "ამონაწერი" в заголовке.
2. **Квитанция платёжного поручения** — квитанция одной транзакции. Парсер извлекает дату, сумму, детали операции и информацию о получателе/отправителе.

!!! info "Как работает парсинг PDF"
    Парсер использует `pdfjs-dist` для извлечения текстовых элементов с их координатами X/Y с каждой страницы. Он динамически определяет границы столбцов по позициям заголовков (например, "Turnover (DB)", "Balance", "Description") и назначает текстовые элементы столбцам на основе их координаты X. Записи даты (`DD.MM.YYYY` при `x < 100`) обозначают начало строки.

#### CSV

Обычный текстовый формат с разделением запятыми. Парсер:

1. Извлекает информацию о счёте из строк заголовка (до первой строки данных)
2. Обрабатывает поля в кавычках со встроенными запятыми (например, `"1,220.09"`)
3. Обрабатывает многострочные описания (строки, не начинающиеся с даты, добавляются к предыдущей строке)
4. Автоматически переводит грузинские ключи заголовков на английский

### Как загрузить

1. **Перетаскивание** — перетащите файл(ы) из вашего файлового менеджера в зону загрузки
2. **Клик для обзора** — нажмите кнопку загрузки и выберите файлы

!!! tip "Несколько файлов"
    Вы можете загрузить **несколько файлов одновременно**. Приложение автоматически объединяет и дедуплицирует транзакции из разных файлов. Это работает для:

    - Нескольких месяцев одного и того же счёта
    - Разных счетов (GEL + USD)
    - Смешанных форматов (например, часть XLSX, часть PDF)

### Определение валюты

Приложение определяет валюту каждого файла по следующей цепочке приоритетов:

1. **Лист информации о счёте** — поле `Account Currency` из заголовков XLSX/CSV
2. **Шаблон имени файла** — обнаруживает коды валют в именах файлов, таких как `MYCREDO_GEL_STATEMENT_...` или `statement_USD.pdf`
3. **По умолчанию** — используется `GEL`

Поддерживаемые шаблоны имён файлов:

| Шаблон | Пример |
|--------|--------|
| `_GEL_` | `MYCREDO_GEL_STATEMENT_2025.xlsx` |
| `.USD.` | `statement.USD.pdf` |
| `-EUR-` | `export-EUR-jan.csv` |
| `GEL.xlsx` | `GEL.xlsx` |
| `STATEMENT_USD` | `STATEMENT_USD.pdf` |

### Дедупликация

При добавлении файлов к существующему набору данных (через кнопку "+ Add Files"), приложение предотвращает дублирование транзакций, используя составной ключ:

```
key = date | debit | credit | operation | currency | balance
```

Добавляются только транзакции, чей ключ ещё не существует. Это означает, что вы можете безопасно повторно загружать пересекающиеся файлы без создания дубликатов.

### Хранение данных

Распарсенные данные хранятся в `localStorage` браузера под ключом `credo_statement_data`. Это означает:

- Данные сохраняются при обновлении страницы и перезапуске браузера
- Данные привязаны к браузеру и источнику (не передаются между устройствами)
- Очистка данных браузера или нажатие "New File" удаляет всё

!!! warning "Ограничения хранилища"
    `localStorage` имеет ограничение ~5 МБ в большинстве браузеров. Для очень больших наборов данных (тысячи транзакций по многим счетам) вы можете приблизиться к этому лимиту. Приложение корректно обрабатывает ошибки квоты — если оно не может сохранить, оно продолжит работать из памяти.

### Использование офлайн

После первой загрузки страницы приложение работает полностью офлайн. Чтобы проверить:

1. Откройте приложение и загрузите его один раз
2. Отключитесь от интернета
3. Загрузите банковскую выписку
4. Панель управления загрузится и будет работать нормально

Единственная функция, требующая интернета — **получение курсов валют** для мультивалютных счетов (из API НБГ).
