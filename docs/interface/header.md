# Dashboard Header

The header is your control center for Credo Analytics. It provides quick access to global settings and privacy tools.

## Controls Overview

| Icon/Button | Name | Function |
| :--- | :--- | :--- |
| **Theme Toggle** | Light/Dark Mode | Switches the interface between a bright, clean look and a dark, eye-friendly theme. |
| **Language** | English/Russian | Toggles the interface language. |
| **Eye Icon** | Privacy Mode | Blurs all sensitive monetary values on the screen. Useful when sharing your screen or working in public. |
| **Filter Icon** | Noise Filter | Hides internal transfers (e.g., self-transfers between your own accounts) to show only "real" spending and income. |
| **Add Files** | Add More Data | Allows you to upload additional statements to merge with your current data. |
| **Trash Icon** | Reset Data | Completely clears all transaction data from the browser and returns you to the welcome screen. |

## Date Range & Transaction Count

In the top left, under the title, you will see a summary of your loaded data:
* **Date Range**: The start and end dates of all transactions currently loaded.
* **Transaction Count**: The total number of transactions being analyzed.

This quick summary helps you verify that you've uploaded all the necessary files for the period you want to analyze.
