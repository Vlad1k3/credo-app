    Обзор панели мониторинга¶

    Панель мониторинга — это основной интерфейс после загрузки файлов. Она предоставляет как общие обзоры, так и детальный анализ ваших финансовых данных.

    Структура макета¶

    +----------------------------------------------+
|  Шапка (управление, счёт, диапазон дат)       |
+----------------------------------------------+
|  Вкладки: Всё | Год | Месяц | Неделя | День | Произв. |
+----------------------------------------------+
|  Навигация по периодам (← текущий период →)   |
+----------------------------------------------+
|                                              |
|  Содержимое вкладки                          |
|  - Карточки сводки                           |
|  - Графики (столбчатые, линейные)            |
|  - Разбивка по категориям (кольцевая + список)|
|  - Сравнение периодов                        |
|  - Финансовая аналитика (только «Всё время») |
|  - Таблица транзакций                        |
|                                              |
+----------------------------------------------+
|  Подвал (примечание о конфиденциальности)     |
+----------------------------------------------+

    Система вкладок¶

    Панель мониторинга имеет 6 вкладок, каждая из которых предоставляет свою временную перспективу:

    Вкладка Отображает Навигация
    Всё время Весь загруженный набор данных Без навигации по периодам
    Год Один календарный год ← 2023 / 2024 →
    Месяц Один календарный месяц ← January / February →
    Неделя Понедельник–воскресенье ← Week 4 / Week 5 →
    День Один день ← 14 Jan / 15 Jan →
    Произвольный Пользовательский диапазон Выбор дат

    Переключение вкладок запускает анимацию затухания-скольжения в области содержимого. Свойство key={activeTab} на обёртке содержимого перемонтирует представление при каждой смене вкладки.

    Вкладка «Всё время»¶

    Отображает полную финансовую картину. Включает:

    • Карточки сводки — доходы, расходы, чистый результат, среднедневной/среднемесячный показатели, текущий баланс
    • Столбчатая диаграмма по месяцам — доходы и расходы за каждый месяц
    • Временная шкала баланса — линейный график совокупного баланса счетов во времени
    • Разбивка по категориям — кольцевая диаграмма + ранжированный список категорий расходов
    • Топ продавцов — ранжированный список продавцов с наибольшими тратами
    • График нормы сбережений — ежемесячные сбережения как процент от дохода
    • Финансовая аналитика — оценка стабильности, «вампирские» расходы, паттерны по дням, тренды категорий, уровень жизни

    Подробности см. в разделе All Time View.

    Вкладки периодов (Год / Месяц / Неделя / День)¶

    Все вкладки периодов имеют одинаковый макет:

    • Карточки сводки — доходы, расходы, чистый результат, количество транзакций за период
    • Столбчатая диаграмма — разбивка по дням внутри периода
    • Разбивка по категориям — категории расходов только за выбранный период
    • Сравнение периодов — сравнение показателей с предыдущим периодом
    • Таблица транзакций — отфильтрована по выбранному периоду

    Подробности см. в разделе Time Periods.

    Навигация по периодам¶

    Когда активна вкладка периода, появляется панель навигации:

    • Стрелка влево (←) — перейти к предыдущему периоду
    • Центральная метка — показывает название текущего периода. Нажмите, чтобы открыть Выбор периода (календарь/список)
    • Стрелка вправо (→) — перейти к следующему периоду

    Стрелки отключаются на границах (первый/последний доступный период).

    Мобильная версия¶

    На экранах уже 768px:

    • Вертикальная компоновка — элементы, расположенные бок о бок (график + список), выстраиваются вертикально
    • Области касания — все интерактивные элементы имеют минимальную область касания 44px
    • Сворачиваемые секции — списки категорий и карточки аналитики сворачиваются до заголовков с раскрытием по нажатию
    • Упрощённые графики — подсказки и эффекты наведения отключены на сенсорных устройствах для предотвращения помех при прокрутке
    • Мобильный список транзакций — настольная таблица заменена компактным списком на основе карточек

    Обработка валют¶

    Если загруженные файлы содержат несколько валют (например, счета в GEL и USD):

    1. В шапке появляется Переключатель валюты
    2. По умолчанию используется валюта основного счёта (первый загруженный счёт)
    3. Нажатие на другую валюту конвертирует все значения по историческим курсам NBG
    4. Каждая транзакция конвертируется индивидуально по курсу на конкретную дату
    5. Конечные остатки из информации о счёте также конвертируются для расчёта совокупного баланса

    Алгоритм конвертации описан в разделе Exchange Rates.
